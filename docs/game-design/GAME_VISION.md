# AETHERFALL: REALMS COLLIDE — Game vision

**Production state:** Pre-production. Mechanics, narrative, realms and playable vertical slice are not yet verified in this repository.

## Confirmed direction

- 3D game project built with Godot 4.x and Blender-authored assets.
- Character-focused art pipeline with named heroes, costumes, gear and standalone weapons.
- Existing S.I.R.E. / HORIZON / GENESIS workflow for authorised development and evidence.

## Design decisions to define

1. Core player loop, win/loss conditions and camera mode.
2. Playable cast, each character's skills and combat roles.
3. Realm ordering, traversal, quests, boss encounters and level scope.
4. Inputs, accessibility and target FPS on each supported device.
5. Save/load, progression, online co-op (if selected) and content rating.

Do not mistake reserved character directories or this proposal for playable mechanics.
