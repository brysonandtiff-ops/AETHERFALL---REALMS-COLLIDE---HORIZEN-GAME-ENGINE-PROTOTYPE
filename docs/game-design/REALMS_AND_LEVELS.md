# Realms and levels

Realm and hub names, sequence, dimensions and gameplay are not yet committed to canon.

New realm work should document the goal, player route, camera, collision/navigation, spawn and checkpoint positions, encounter gates, performance budget, assets, save transitions and playtest proof.

Place Godot scenes under `game/scenes/levels/realms/`; editable environment source under `art/blender/environments/` and exported GLBs under `game/assets/worlds/realms/`.

Only add level-specific folders once a realm is approved. The pre-created categories do not claim that levels have been built.
