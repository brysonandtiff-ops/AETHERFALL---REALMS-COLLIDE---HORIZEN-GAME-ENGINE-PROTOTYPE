# Shadowspire → AETHERFALL recovery: design only

**26 November 2026. No original game code transferred. No repository deleted.**

The connected GitHub account has no owned standalone Shadowspire repository. S.I.R.E.'s [issue #275](https://github.com/brysonandtiff-ops/SIRE/issues/275) documents historical local-only Godot source and separate Unreal work that are not accessible to the current GitHub connection. The [draft documentation import #746](https://github.com/brysonandtiff-ops/SIRE/pull/746) has a Shadowspire PDF/PPTX, not the recoverable Godot/Unreal repository.

## What was preserved

- A candidate Witch Rogue → Wraith → crystal anchor → relic extraction mission, with input/save test requirements.
- Gothic eclipse style, Floating Gothic City, Crystal Forest and Shadow Ruins environmental proposals.
- Living-weapon evolution and companion design, all concept-only.
- Owner-selected five tanks and five supports (see `../characters/LEGACY_ROSTER.md`). Eight additional empty AETHERFALL character asset locations are reserved; Vellaris and ThornDell asset paths remain unchanged.

## Preservation boundary

No original `.blend`/`.glb` models, Godot scripts/scenes, Unreal source, saved games or canonical reference-image bytes are claimed as transferred. Existing original files must stay where they are until individually recovered and hashed. Do not replace AETHERFALL-approved artwork with historical concept art.

**Repository deletion is blocked.** No owned GitHub Shadowspire repository could be located; the available GitHub tools cannot delete repositories. Nothing was deleted. A verified source identity, complete immutable backup, file/history comparison and native-asset review would be necessary before any irreversible removal. See `shadowspire_migration.json`.

Provenance: `Shadowspire_NotebookLM.pdf` (18 October 2026), owner roster lock records (26 November 2026), [SIRE issue #275](https://github.com/brysonandtiff-ops/SIRE/issues/275), and [source recovery branch](https://github.com/brysonandtiff-ops/SIRE/tree/feat/shadowspire-sovereign-source-recovery-20261024).
