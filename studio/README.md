# AETHERFALL — Studio systems (production contract only)

This is the **studio contract**, not a new AI agent, build engine or alternate game. The actual native Godot project remains at `game/project.godot` and authorised master systems remain external S.I.R.E. / AXIOM G.A.I.S. / HORIZON workflows.

- `layout_manifest.json`: machine-readable studio ownership zones, reserved runtime modules, content boundaries, protected paths and generated-data locations.
- `../config/toolchain.json`: truthful engine/DCC and tooling version/connection inventory.
- `../docs/architecture/AAA_STUDIO_ARCHITECTURE.md`: human-readable AAA structure and published Unreal-to-Godot mapping.
- `../tools/validate_studio_layout.py`: fail-closed path/engine/asset-contract validator.
- `../docs/production/CONTENT_HANDOFF.md`: what art/engineering/QA must supply before an asset ships.

The directory contracts describe planned responsibilities. A reserved folder is **not** proof of working code, actual multiplayer, model imports, running releases, a live tool connection or team members.
