# Skill: independent QA and evidence

First inspect exact commit/work order. Run Python contract tests, actual native Godot import/boot, then when a graphical runner exists capture real device/engine video, inputs, animations, saves, FPS and source hashes. Verify an independently captured file, not agent self-report.

States are PASS, FAIL, NOT_RUN or BLOCKED for each distinct gate. Source-only tests cannot mark gameplay/Android art done. Preserve original screenshots/video and provenance, never simulate live proof.
