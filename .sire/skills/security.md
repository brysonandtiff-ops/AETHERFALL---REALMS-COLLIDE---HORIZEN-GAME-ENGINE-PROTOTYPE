# Skill: security and permission review

Existing S.I.R.E. Secrets Steward/Plugin Permission Matrix remain authority. Review files for credentials, wildcards, unsafe process spawn, path traversal and unapproved network. No secret value in work orders, logs, artifacts or manifest.

Source validator is name-based security, not a complete secret scan. External plugins require an approved manifest, capability allowlist and runtime authentication before any call. No automatic cost/deploy.
