# Skill: S.I.R.E. Git stewardship

Route Git changes to the existing S.I.R.E. Git Stop/Git Team (upstream `python -m sire git-stop check` from an authorised S.I.R.E. checkout). Inspect exact branch/commit, check dirty worktree, run relevant tests. Prefer a draft PR, never force push, reset shared history, bypass hooks or auto-merge.

This AETHERFALL skill does not install another Git agent or grant credentials. Local CLI checks do not replace S.I.R.E.'s upstream authority.
